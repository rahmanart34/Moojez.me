# مدرّب القدرات والتحصيلي

موقع ثابت (HTML + JSON + صور) ينشر مباشرة على GitHub Pages.

- `index.html` التطبيق كامل
- `bank.json` بنك الأسئلة (500 سؤال) مع ربطها بدروس كتب الوزارة
- `img/` صور الأسئلة والأشكال

ملاحظة: «المدرّب الذكي» و«الترتيب» يشتغلان فقط داخل Claude. خارج Claude يحتاجان خادماً خاصاً (مفتاح Claude API وقاعدة بيانات).
