# موجز

مدرّب القدرات والتحصيلي: بنك أسئلة مربوط بكتب وزارة التعليم، كوينز، وترتيب للطلاب.

## محتوى المستودع

| الملف | المحتوى |
| --- | --- |
| `public/index.html` | التطبيق |
| `public/bank.json` و`public/img/` | بنك الأسئلة وصوره |
| `public/_worker.js` | الخادم وقاعدة البيانات D1: تسجيل الطلاب (الاسم والجوال)، الكوينز، الترتيب، وصفحة الإدارة |
| `public/_routes.json` | يخلي الخادم يشتغل بس على روابط `/api/*` |
| `public/admin.html` | صفحة الإدارة (moojez.me/admin.html): تعرض كل المسجّلين وتحمّلهم Excel |

## إعدادات Cloudflare (في لوحة التحكم، مو في المستودع)

- مشروع Pages مربوط بهذا المستودع، والمجلد المنشور: `public`، وبدون أمر بناء
- ربط قاعدة البيانات: D1 باسم `moojez` على المتغير `DB` (الجداول تنسوى تلقائياً أول مرة)
- السر `ADMIN_CODE`: كود صفحة الإدارة، ولا ينحط أبداً في المستودع
- الدومين: moojez.me (النيم سيرفرات في GoDaddy موجّهة لـ Cloudflare)

## الخصوصية

أرقام الجوال ما تطلع في الترتيب ولا لأي طالب. تطلع بس في صفحة الإدارة بعد كود الإدارة.
